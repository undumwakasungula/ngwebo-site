# Ngwebo Website

Next.js + TailwindCSS site for Ngwebo, with a secure backend API for contact form submissions.

## Deployment

- Build command: `npm run build`
- Output directory: `.next`
- Environment variables:
  - `SENDGRID_API_KEY`
  - `SENDGRID_FROM_EMAIL`
  - `SENDGRID_TO_EMAIL`
  - `SENTRY_DSN` (optional)

## Local setup

```bash
npm install
npm run dev
```
